================================================================================
                           PROJECT DOCUMENTATION
================================================================================

PROJECT NAME: AURUM - Luxury Perfume E-Commerce Website
PROJECT TYPE: Single Page Application (SPA) / E-Commerce Website
TECH STACK: React, React Router, Tailwind CSS, Framer Motion, Vite
BRAND: AURUM - Maison de Parfumerie (Est. 1924)

================================================================================
                            PROJECT OVERVIEW
================================================================================

AURUM is a luxury perfume e-commerce website that offers a premium shopping 
experience for high-end fragrances. The brand represents elegance, exclusivity, 
and timeless beauty in the world of perfumery.

KEY BRAND ELEMENTS:
- Brand Name: AURUM (Latin for "Gold")
- Tagline: "Discover Your Signature Scent"
- Aesthetic: Luxury, dark, elegant with gold accents (#c9a45c)
- Typography: Playfair Display (serif headings), Cormorant Garamond (body)
- Color Palette: Dark backgrounds (#080608, #110f14, #0d0b0f), Gold accents (#c9a45c)

================================================================================
                           FUNCTIONALITY
================================================================================

1. HOME PAGE
   - Full-screen video hero section with brand introduction
   - Featured fragrances section (4 products grid)
   - Best sellers carousel with auto-rotation and manual navigation
   - Category browsing (Men, Women, Luxury, New Arrivals)
   - Cinematic video section showcasing the craft
   - New arrivals section
   - Customer testimonials with auto-rotation
   - Newsletter subscription for exclusive offers
   - Smooth scroll animations using Framer Motion

2. PRODUCT LISTING PAGE (/products)
   - Grid display of all perfume products
   - Category filtering (Men, Women, Luxury)
   - Product cards showing:
     * Product image with hover effects
     * Brand name (AURUM)
     * Product name
     * Size and fragrance type
     * Price (with original price for sale items)
     * Badges (Best Seller, New, Sale)
     * Quick add to cart functionality

3. PRODUCT DETAIL PAGE (/product/:id)
   - Full product information display
   - Product images/videos gallery
   - Complete fragrance notes breakdown:
     * Top notes
     * Middle/Heart notes
     * Base notes
   - Size selection
   - Quantity selector
   - Add to cart functionality
   - Rating and reviews display
   - Related products suggestions

4. SHOPPING CART (/cart)
   - Cart items display with images
   - Quantity adjustment (increase/decrease)
   - Remove item functionality
   - Size selection per item
   - Subtotal calculation
   - Coupon code application
   - Discount support
   - Total calculation
   - Proceed to checkout button

5. CHECKOUT PAGE (/checkout)
   - Shipping information form
   - Order summary
   - Continue to payment button

6. PAYMENT PAGE (/payment)
   - Payment form interface
   - Order review
   - Place order functionality

7. ORDER CONFIRMATION (/order-confirmation)
   - Success message
   - Order details summary
   - Continue shopping option

8. USER AUTHENTICATION (/login)
   - Login/Signup form
   - User authentication interface

9. CONTACT PAGE (/contact)
   - Contact form
   - Company information

10. ABOUT US PAGE (/about)
    - Brand story
    - Company history
    - Craftsmanship details

================================================================================
                           TECHNICAL FEATURES
================================================================================

1. STATE MANAGEMENT:
   - React Context API for cart management
   - CartContext for global cart state
   - Reducer pattern for cart operations

2. ROUTING:
   - React Router v6+ for client-side routing
   - Nested routes with shared Layout component

3. ANIMATIONS:
   - Framer Motion for complex animations
   - Scroll-triggered animations
   - Hover effects on products
   - Page transitions

4. STYLING:
   - Tailwind CSS for utility classes
   - Custom CSS for specific styling
   - Responsive design (mobile, tablet, desktop)

5. MEDIA:
   - Background videos on multiple sections
   - Product videos for certain fragrances
   - High-quality Unsplash images

6. CART FUNCTIONALITY:
   - Add items to cart
   - Remove items from cart
   - Update quantity
   - Apply coupon codes
   - Calculate discounts
   - Calculate totals (subtotal, total)

================================================================================
                           HOW TO RUN
================================================================================

1. Install dependencies:
   npm install

2. Start development server:
   npm run dev

3. Build for production:
   npm run build
